## ローカルで確認する

```
open index.html
```

もしくは任意の静的サーバーで配信してください（例: `python3 -m http.server`）。

## GitHub Pages で公開する

1. GitHub のリポジトリ画面で **Settings > Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. Branch を `main` / フォルダを `/ (root)` に設定して Save
4. 数分後に `https://haly-coder.github.io/sankou-medexikku-lp/` で公開されます

## 編集が必要な箇所

`index.html` 内の以下はプレースホルダーです。実際の情報に差し替えてください。

- 会社概要セクションの所在地・設立・代表者
- お問い合わせのメールアドレス・電話番号
- 製品名・仕様（一例として記載しています）
